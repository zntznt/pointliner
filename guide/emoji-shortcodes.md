# Emoji shortcodes

*Part of the [Pointliner guide](README.md). The full list of `:shortcode:` names you can type to
drop in an emoji, grouped by theme. For how the picker and matching work, see
[Writing and formatting](writing-and-formatting.md#emoji).*

---

Type a colon and part of a name (`:drag`) to open a picker, or type the whole shortcode
(`:dragon:`) and it becomes the emoji when you finish it. Matching is anywhere in the name, so
`:face` finds every face. When a glyph has more than one name, any of them works; the first
column shows the glyph, the second its main shortcode, the third the other names for the same
glyph.

There are 567 shortcodes covering 525 emoji. The last section is a solo-RPG
lean for a game journal (dice, swords, monsters, keeps and loot), the set Pointliner leans on that
a general emoji list would not carry.

> This page is generated from the app, so it always matches what you can type. If you are editing
> it by hand, you are editing the wrong place: change the `EMOJI` map in `index.html` and
> regenerate.
